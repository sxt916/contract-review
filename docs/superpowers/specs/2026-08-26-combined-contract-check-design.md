# 对比与审核独立工作流设计

## 目标

保留现有“合同对比”和“金额审核”两套独立功能的页面、接口、任务状态和结果列表，只在右上角导航中增加第三个“对比与审核”入口。新入口使用独立任务模型，对每份 Word 合同独立执行审核，对配对成功的 Word/PDF 同时启动对比。

## 范围与隔离边界

- `comparison.html`、`comparison-results.html`、`/api/comparisons` 和原对比 Worker 恢复到本次改造前的行为，不返回、不展示、不执行金额审核。
- `amount-review.html`、`amount-review-results.html`、`/api/amount-reviews` 和原审核 Worker 保持现有行为。
- 两个原功能的唯一界面变化是顶部导航新增第三个入口。
- 新页面使用 `contract-check.html` 和独立的脚本、结果页、API 路由及数据表，不再通过 `auto_review` 标志复用对比任务。

## 数据模型

新建 `combined_check_tasks` 表，每份 Word 对应一行，主要字段包括：

- 任务标识、合同编号、Word 文件名及临时路径。
- 可空的 PDF 文件名及临时路径。
- 独立的 `comparison_status` 与 `review_status`。
- TextIn 任务标识、预览地址、相似度、差异数及对比错误。
- 审核问题、审核摘要、解析器版本及审核错误。
- 创建、对比完成和审核完成时间。

未配对 Word 的 `pdf_filename` 和 `pdf_temp_path` 为空，`comparison_status` 为 `not_applicable`；页面将扫描合同和对比结果显示为“—”，但正常展示审核进度和结果。

## 提交和配对

`POST /api/combined-checks` 接收 Word、PDF、配对清单、未配对 Word 索引和对比忽略选项。服务端校验下列约束：

- 每个 Word 索引最多出现一次，必须位于配对清单或未配对清单中。
- PDF 只能出现在一个配对中。
- 至少选中一份 Word；即使没有任何配对，也允许提交审核任务。
- 仅保留配对 PDF 和所有提交 Word 的临时文件，其他 PDF 立即删除。

配对预览会将未配对 Word 显示为“仅审核”行，确认按钮在有任意 Word 时可用。

## 并行处理

后台 Worker 为合并任务提供两个互不依赖的处理器：

1. 对比处理器领取 `comparison_status='queued'` 的配对任务，将 Word/PDF 提交至 TextIn 后转为 `processing`，之后独立轮询结果。
2. 审核处理器领取 `review_status='queued'` 的所有 Word，不查询、不等待对比状态，直接执行本地 DOCX 审核。

对比是远程异步任务，Worker 在提交对比后即可处理本地审核，两个状态可以同时显示“处理中”或先后独立完成。

Word 文件需同时服务于对比提交和审核。两个处理器完成各自的读取后，只有在对比已成功提交或不适用，且审核已完成或失败时，才将 Word 临时文件删除。PDF 在 TextIn 提交成功后删除。

## 页面与上传交互

`contract-check.html` 的 Word 和 PDF 区域都提供两个并列按钮：

- “选择文件”使用普通多文件选择器。
- “选择文件夹”使用目录选择器。

两种方式共用同一份候选列表；每次新选择默认勾选全部合法文件，用户可逐份取消或使用全选/取消全选。按钮自身处理点击，不依赖整个拖拽区的冒泡事件，避免文件与文件夹选择器互相拦截。

`contract-check-results.html` 只查询合并任务，包含标准合同、扫描合同、对比结果、审核结果、创建时间和操作。审核未通过时可展开具体原因。

## 错误和恢复

- 对比失败不会终止或覆盖审核结果；审核失败也不影响对比轮询。
- Worker 重启时分别恢复中断的对比提交状态和审核状态。
- Web 页面会同时轮询两个状态，直到各自进入终态。
- 本地开发和验收时必须同时启动 Web 和 Worker；不再只启动 Web 后宣称任务可处理。

## 现有任务迁移

将当前 `comparison_submissions` 中 `auto_review=1` 的行按原 ID 迁移至 `combined_check_tasks`，保留文件路径、TextIn 任务标识和已有状态。迁移成功后才删除原行，以使当前两条等待任务可由新 Worker 继续处理，同时不污染独立对比结果。

## 验证

自动化测试必须覆盖：

- 原对比 API 只创建对比任务，完成后不执行审核。
- 原金额审核 API 和页面保持既有行为。
- 合并任务的审核可在对比完成前进入终态。
- 未配对 Word 会创建、显示并完成审核，对比列为空。
- 文件和文件夹两个选择器可独立打开，目录文件默认全选且可取消。
- 当前已排队的合并任务在迁移后仍存在且可处理。
- 页面导航在所有工作页显示三个入口。
